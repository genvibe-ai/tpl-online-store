# Notice

Fernlace is a GenVibe online store template.

## Upstream

Based on GoCart by GreatStackDev (MIT). Source: https://github.com/GreatStackDev/gocart

The storefront structure follows GoCart: announcement banner, navbar with search and bag count,
hero, product grids with ratings, "our specifications" promise strip, newsletter, shop page with
search, product page (image gallery, description and reviews), cart with quantity counter and an
order summary with coupon codes. The code was ported from Next.js and Redux to Vite, React 19,
TypeScript, Tailwind CSS 4, React Router and a small Zustand store, then redesigned and extended
(bag drawer, filters and sorting, size variants, checkout and order confirmation, journal and info
pages). GoCart's seller and admin dashboards, Prisma schema and images are not included. GoCart's
license text is kept in `LICENSE-UPSTREAM`.

## Fictional content

"Fernlace" and every product, price, ingredient claim, review, reviewer, person, quote, number,
address and company in this template are fictional. The store is a demo: no payments are taken
and no orders are fulfilled.
